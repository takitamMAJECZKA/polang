# Benzin Language Support

To jest oficjalne rozszerzenie do VS Code dla języka **Benzin** (.bzn).

## Funkcje
- Kolorowanie składni dla słów kluczowych (np. `zmienna`, `pisz`, `jezeli`).
- Obsługa komentarzy (`//`, `/* ... */`).
- Obsługa stringów i liczb.

## Instalacja (Lokalna)

1. Skopiuj cały folder `vscode_extension` do folderu rozszerzeń VS Code:
   - **Windows**: `%USERPROFILE%\.vscode\extensions\benzin-lang`
   - **Mac/Linux**: `~/.vscode/extensions/benzin-lang`
2. Zrestartuj VS Code.
3. Otwórz dowolny plik `.bzn` - składnia powinna być kolorowa!
